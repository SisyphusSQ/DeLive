# 完整云端备份与恢复

设置 → 云端备份支持夸克 CLI、S3 和 WebDAV。三种服务共用 `.delive` 版本化包与恢复规则。自动备份默认关闭；启用后在录制停止、数据落盘后执行，后续图片、稿件、AI、标签或主题变化会合并调度。录制中不读半成品，也不会因备份成功删除本地原件或远端旧备份。

## 夸克入口与权限

填入本机已安装受限包装器的绝对路径（`quark_runtime.py`，或提供相同 `status` / `run` 协议的固定可执行入口）。路径由用户配置，产品不写死插件缓存版本。若插件升级改变路径，请由 CLI 管理方维护固定入口或重新选择路径。已验证 Go 0.1.0 协议；其他版本明确拒绝并提示通过 CLI 处理。Python 包装器从 Homebrew 或系统路径查找 Python。

“测试连接”检查运行状态并调用 CLI 用户信息命令确认授权；READY 本身不代表已登录。应用不读取/复制凭据、不展示二维码、不安装或升级 CLI。入口缺失、版本不符、未授权或过期均须在 CLI 侧解决。每台机器分别验证授权。

默认目录 `ai-agent/coding/delive/backups/`，首次实际备份逐级创建并回读，每次上传显式传入父目录 FID。不创建公开分享。目录只能位于 `ai-agent/`，使用小写字母、数字和中划线，临时资料允许 `_scratch`。

## 内容与格式

- 会话、所有稿件、说话人、标签、主题、AI 结果、图片原件/说明/时间和相对引用；默认包含原音全部轨道及索引。
- 可主动取消原音，文件名和列表明确“不含原音”，恢复时清除无实体的录音引用。缺少任何应有素材、摘要不符或磁盘不足都失败，不报告完整成功。
- 普通显示和 AI 模型设置可迁移；API 密钥、服务凭据、云配置、CLI 程序路径、Codex Home 内容不进包。恢复保留本机凭据和机器连接配置。
- 包由格式标记、清单长度/摘要、JSON 清单和顺序文件流组成。清单有版本、相对路径、大小、SHA-256；流式读写，不把全部原音放进内存。清单上限 64 MiB；不压缩已有媒体。
- 旧 `.json` 仍可恢复，但仅是文字/元数据备份，没有图片或原音实体。数据管理中的 JSON 导出也明确此范围。

## 上传与失败

创建本地包后先持久化任务，再上传。CLI 返回 `recordId` 后立即保存；逐项结果和最终结果都需确认。所有服务上传后回读列表、大小，再下载核对完整 SHA-256，才标记完成。

夸克返回的 FID 是不稳定的包装字符串；列表用唯一备份文件名定位，每次实际下载重新取得 FID。任务保存最近上传回读 FID、父目录、名称、大小、摘要和原任务号。中断或未知结果显示“检查 / 继续原任务”，按原任务号查询/续传；未确认的任务会阻止自动另建上传。S3/WebDAV 对原对象回读对账，不盲目重复 PUT。

失败与未知不会写入自动备份成功指纹。自动调度同一内容不反复重试；用户可在设置中检查原任务，或修复原因后手动备份。进度/错误可见，错误文本隐藏授权信息和 URL。

## 恢复事务

下载到独立暂存目录，校验版本、路径、文件数量、大小、摘要和素材引用后才提供恢复选项。合并保留本地相同 ID；共用已有录音 ID 的新会话也作为冲突保留本地，避免覆盖其原音。覆盖前展示会话/标签/主题数量及冲突范围，并创建含原音的本地回退包；当前资料不能完整备份时停止覆盖。

恢复期间禁用操作并停止 AI 任务。文件先暂存，原音放在目标卷旁再原子重命名；旧素材保留于回退位置。主进程记录恢复日志，前端在一个 IndexedDB 事务中提交会话、设置/标签镜像和事务标记。随后更新 localStorage 镜像并提交文件事务。应用重启时先恢复事务，再加载会话和清理素材：有数据库提交标记则完成收尾，否则回退文件。

“本地恢复回退包”提供同一套校验和覆盖流程。回退包在当前应用数据目录的 `backups/`，不自动清理。临时下载、完整本地包和回退包会占磁盘，须按实际保留需求管理；不要在恢复进行时手工修改该目录。
