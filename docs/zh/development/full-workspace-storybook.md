## 设计档案

主要使用者是在桌面记录、阅读和整理会议的人。高频任务是开始/停止录制、找到会议、读稿回听、核对修订；配置、导出和恢复作为相对低频任务集中组织。

- 延续已认可的舒适笔记式方向。回顾用连续正文、轻量元信息与固定播放器；录制以音源和控制为先；文件按来源、就绪条件、任务结果排列；主题采用资料夹列表与会议条目；设置使用分组导航和连续表单。
- 使用项目原有字体及系统中文回退。页面标题约 28px，分组标题 16–18px，正文 14–15px，辅助文字 11–13px；留白服务于阅读，避免每个字段再套卡片。
- 沿用八种主题 token 和明暗模式，导航偏中性灰阶，主题色用于选中项与主操作。错误有文字说明，危险动作有确认；深色下提高危险文字对比。
- 统一 8–24px 的组内间距、约 40px 的桌面内容边距、6–12px 控件/容器圆角。页面分组使用轻边框或分隔线，阴影用于弹层。主要按钮至少 34 CSS px。
- 继续使用 React、现有主题、lucide、Sidebar、Select、ActionDialog、AppearancePanel、PreviewDialog 和笔记式预览；未引入依赖。高副作用设置使用预览状态模拟，不把正式备份/运行时组件接到真实服务。
- 设置根据可用内容宽度把分组导航移到表单上方；主题卡片变为单列；回顾保留原有窄窗会议列表与播放器布局。减少动态效果偏好下停用预览动画。
- 弹层支持 Escape、焦点约束和返回；菜单继续使用应用内 Select；设置未保存时，侧栏、命令面板和分组切换都经过离开确认。

## 隔离与交接边界

- 只使用合成会议、图片、静音 WAV、示例地址与凭据。不得在预览中填写真实秘密。沿用 Storybook 同源 CSP、无业务代理和 Electron 拒绝启动保护。
- 设置修改、主题与导入操作只改变当前预览状态。刷新/重置还原合成资料，外观和侧栏偏好在浏览器来源内保留；不代表正式磁盘持久化。
- 文件拖入仍使用合成样本，不读取个人文件。JSON 导入使用固定样本；JSON/诊断导出展示内容与完成反馈，不写文件。已有导图导出仍可下载合成 SVG/PNG。
- 备份列表与校验/恢复为固定场景，不上传、下载或恢复真实资料，不承诺真实任务幂等性。更新与本地模型准备只模拟操作状态。
- 同一预览中的云端文件任务仍遵守已有「单条任务先恢复后提交」限制；导入音频与已有会议复用合成内容，不模拟无限数量真实任务或自由 AI 生成。
- 用户确认整套设计后，再按正式页面组件接入。正式接入需保留现有全部字段与错误语义，单独验收真实录制、ASR/AI、对象存储、备份事务、重开持久化、Electron 缩放、快捷键及系统权限。本轮未授权进入该阶段。
