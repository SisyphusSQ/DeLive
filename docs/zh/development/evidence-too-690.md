## 对抗式审查与修复

- 关闭 Shell 后仍暴露 apply_patch：改为临时模型元数据禁用工具，使用真实 CLI 对抗样本回读。
- 旧 AI Key 在安全存储失败时可能回退明文，以及其他设置保存可能重新落盘解密值：严格拒绝回退，统一持久化占位与导出脱敏；迁移各类凭据独立尝试，避免一类失败跳过另一类。
- 渲染器崩溃/页面重载未关闭任务，以及连接检测不受退出生命周期管理：为任务和检测注册崩溃、导航、销毁和应用退出取消。
- 获取模型期间切换服务可能混入旧模型列表：使用标准禁用 fieldset 固定本次连接配置。
- 旧配置省略地址时不能启用 AI：恢复默认地址语义并加入回归断言。
- 模拟 Finder 的系统 PATH 时，npm Codex 启动报 `env: node: No such file or directory`：仅为子进程补充常用安装目录，保持默认 Home 与全局环境不变。
- 导入备份不接受 Codex 可执行路径，避免外来备份改变本机执行程序。
- 最终包验证发现内建 openai provider 禁止通过 model_providers 覆盖重试参数；移除该覆盖，保持默认 Home 的 provider 策略。DeLive 自身仍不重发或切换通道。
