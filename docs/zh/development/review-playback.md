# 原音回放、版本校对与导出

TOO-685 开发实现，复用前置卡的原音资产、公共时间轴和稿件版本。正式三人会议、硬件听感/偏移及长期资源验收移交 TOO-686。

## 用户流程

1. 打开「回顾」并选择会话，或从文件转写任务打开结果所在会话。
2. 「查看稿件」可查看实时稿、会后稿、自动校正版、人工修订或历史原稿；点击「采用为当前稿」才改变导出与 AI 来源。「对照」选择另一份稿件并排查看；窄窗口按上下排列。已采用版本随会话重新打开恢复；单纯查看不改变该选择。
3. 点击带时间的文字即可定位原音。播放器可选择同步混音、系统声音或麦克风，并显示公共时间轴位置和来源/中断记录。按说话人筛选仅影响当前稿件的显示，不改变导出内容。
4. 没有原音的历史会话显示明确提示，文字可继续使用；原音缺失/损坏/读取失败时暂停并提示。录音时间缺口或该来源无音频时不会替换为其他来源，提供「跳到下一段可用原音」。
5. 「校对当前稿件」可修改匿名姓名、每句文字、归属和逐句时间，也可新增本会话匿名说话人。录音中禁止校对。点击「保存为修订版本」等待保存成功，才会显示确认；编辑草稿尚未保存时导出仍使用已保存版本。切换版本/放弃校对需确认丢弃当前草稿，草稿保存在本机，切页与重开可恢复；存储失败会明确提示，仍需保存为修订版本。
6. 每次保存生成独立版本，保留父版本、创建时间和编辑说明。原始实时/会后结果与所有此前人工版本均保留；新的会后结果不改变已经选中的人工稿。
7. 「人工确认跨版本说话人映射」选择姓名来源稿件，逐项确认对应关系，再确认另存修订版本。复制的是用户明确选定的显示姓名，双方匿名 ID 与原稿均不修改；允许人工确认多项对应同一姓名，但不会自动合并身份，也没有跨会议人物库。
8. 「导出当前版本」提供 TXT、Markdown、SRT、VTT。文字、说话人标签、逐句时间来自同一选定稿件；临时片段在文字导出中保留状态标识，未知标签不强行归人。SRT/VTT 按开始时间排序，保留重叠区间，不挪动时间来伪造无重叠。
9. 没有有效逐句时间的稿件仍可导出 TXT/Markdown；SRT/VTT 禁用并解释原因。用户可以在校对中显式填写起止时间后导出字幕，不自动以字数或总时长估算。旧译文作为独立历史译文候选保留，只有译文的旧会话默认展示译文；旧 AI/人工校对纯文字结果作为独立修订候选保留，不凭旧稿时间强行对齐。
10. TOO-707 的「另存恢复修订」用已有结构化会后稿恢复可定位正文，旧全文仍可对照或重新采用。完成恢复后按需逐句补回人工修改。仅录音和导入文件的会后稿也支持同一套按人筛选、回听及采用后导出。

## 数据与并发

会话 schema 6，兼容旧数据，新增可选 editNote 和 merge 来源/审阅记录。versions[] 使用不可变快照，人工版本 kind=edited、parentVersionId 指向来源。speakerMapping 记录 sourceVersionId、confirmedAt、pairs；同一编号永远不是跨版本自动映射依据。

旧会话按需投影为原稿版本；保存选择或校对时持久化。后续实时修订如改变了原稿内容，会暴露一个新的原稿候选，已有人工稿保持选择。编辑过程中原始内容发生变化时，保存会保留编辑开始时的来源快照，避免父版本指向后来不同内容。

会后结果补入和人工保存按会话串行执行，基于提交时最新数据合并，避免两个异步写入相互覆盖。IndexedDB 失败会向界面返回错误，不显示保存成功；可以保留编辑内容后重试。导出按明确字段构造，不序列化完整会话、响应包、配置、凭据或临时 URL。历史列表的已版本化会话导出也使用当前所选版本。

会议来源 system / microphone / mix 是音频轨道，不是说话人身份。说话人 ID 由实时识别段/会后任务限定，界面未知、临时、稳定、人工状态与来源分别展示。

## 回放实现

RecordingPlayer 按清单定位分片，以 AudioContext 时钟与 80ms 初始缓冲调度；只预读约 4 秒后续音频，分片结束即释放节点。不会拼接整场会议到单个内存音频对象，也不累加 IPC 往返时间作为播放时钟。

读取跟不上调度时明确暂停，不悄悄跳帧。暂停、换轨、重新定位和组件退出会使旧异步读取失效，防止旧片段在新位置开始播放。缺口前暂停，下一段按钮使用清单真实时间，不压缩公共时间轴。

原音 readBlock 仅检查目标分片目录、元数据、文件类型/长度与 PCM WAV 头，避免每读一个分片都重扫整场会议导致平方增长。完整清单仍在打开原音时做一次恢复/校验；损坏资产不会伪装可播放。

开发脚本核对实际 AudioBufferSourceNode.start 的分片 offset 与文字时间，调度偏差小于 1ms；这只证明软件定位参数，不是物理扬声器/耳机输出时延或 ASR 时间准确度。正式播放偏差、长会议漂移与资源阈值须在 TOO-686 确认并实测。
