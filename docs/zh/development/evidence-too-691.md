## 审查发现与修复

- 首次真实图表问答返回正确数值但缺少来源链接。改用 Schema `imageIds`，校验 ID 属于生成时快照，并由 UI 生成链接；问答 citation 显式区分 text/image，拒绝不存在的来源。
- 既有 IndexedDB 写失败会静默切到 localStorage，单条写入在 request success 时提前返回。为防止元数据未提交就删除原图，改为事务完成确认和显式错误；启动读取失败时阻止新任务/清理，旧数据保留。原 localStorage 数据的正常迁移保留。
- 图片子弹窗 Escape 会同时关闭父回顾页；父页面现在忽略子模态窗口期间的快捷键。
- 在这台机器上使用默认硬件输出的合成音频图停滞在约 5 ms。测试改用平台静音 sink 后，点击选择约 0.9 s、粘贴约 2.7 s、拖入约 3.2 s，与原音一致。这证明应用音频时间基准；没有将其标为物理麦克风/扬声器或真实硬件中断校准通过。

## 边界

本卡提供图片元数据与相对文件契约；完整云端备份/恢复归 TOO-692。单张 AI 输入 12 MiB、每块约 24000 字符、最多 64 块、汇总 128000 字符；超过边界明确失败，无尾部截断。校对超出完整单块上限明确拒绝。不同视觉模型的理解质量不能由一次图表验收保证，用户应复核来源。
