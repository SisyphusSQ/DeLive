## 对抗式 Review

已处理的真实风险：
- 原回顾页只保留有 speakerId 的片段，导致未知说话人丢失；改为全部片段可见并提供未知筛选。
- 原播放按钮没有行为；接入分片原音和独立来源，不能在缺片时假装播放或悄悄换轨。
- 每次读取分片原先重扫整场录音，长会议回放/文件导出出现平方增长；改为目标分片读取与格式校验，补充损坏/无关块回归。
- 以 IPC 完成时间串接会累加偏移；改为音频时钟、有界预读、取消 generation 和缺口暂停。
- 会后结果和人工版本异步写入可能互相覆盖；按同会话串行、基于最新版本合并，持久化失败不更新已保存状态。
- 当前版本与旧 tokens/校对文本可能不一致；版本化导出只读取选中版本的片段/姓名/时间，不把旧 tokens 或其它版本混入。
- 原页面还支持只有译文的旧会话；保留独立历史译文候选，默认展示可用文字，补充针对性回归。
- 旧纯文字不能被强制套用估计时间；TXT/MD 保持可用，字幕需有效逐句时间。保留旧校对结果为独立候选。
- 来源快照正规化只比较共享字段，避免 recognitionId 等原始字段导致虚假的重复原稿。
- 同号不等人：映射另存新修订，并记录确认来源与配对，原有姓名和 ID 不变。

没有实现声纹、跨会议身份、云端协作或第二套录音/ASR。未保存编辑草稿离开页面前需显式保存；导出始终使用已保存版本。
