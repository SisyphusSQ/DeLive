## 布局和行为约定

- 采用现有主题变量与字体回退。默认以浅色内容区、灰阶导航、少量主题色区分层级。主操作最少 34 CSS px 高，时间用等宽数字。错误、禁用、进行中均有文字或图标提示。
- 录制首屏保留音源和开始动作。录制控制随滚动持续可达。文件和设置在窄窗允许分组换行，主要内容独立滚动。
- 回顾区域可用宽度不足时，把会议列表移到回顾上方独立滚动，保留搜索、日期与当前会议。正文与播放器保持独立，版本采用标记保留。没有会议列表收起按钮。
- 从文件配置返回时保留来源类型和所选音频。回顾返回保留会议、稿件和编辑上下文。保存设置后继续由用户发起录制或提交。回顾和文件的火山任务引用同一条模拟任务。预览同时跟踪一条火山任务，有待保存或待清理状态时先完成恢复，再提交新任务。任务行打开对应的会后稿或校正版，已有未保存草稿时优先保留编辑。删除来源会议后，原任务仍可查询或清理，结果不再写回该会议。
- 先按 Tab 找主要操作，用方向键和 Enter 操作应用内选择器。Escape 退出弹层并归还焦点。命令面板支持 Cmd/Ctrl+K 和页面名称搜索。正式应用缩放仍以 Electron 的 Cmd +/-/0 行为为准。

## 开发验证

已在隔离 Chromium 中点验 4 组核心工作台自检和 5 组既有回顾自检。录制链路经过系统声音选择、Escape 归还焦点、插入合成图片、录制中切页、保存及打开原会议。文件链路覆盖分项配置、模拟保存失败、配置返回、任务查询、本地补存、匿名说话人、逐句定位及原文 SRT 入口。真实浏览器点击从定位点播放和暂停静音样例。八种配色均在明暗两种模式下切换过。

实际查看了 1280×900、800×600 和 533×400 CSS px 的页面。533×400 用于接近最小窗口在 150% 缩放下的内容空间，验证了可滚动的会议列表、稿件采用标记、播放器、菜单边界和 Escape 焦点归还。修正了录制按钮图文换行、深色录制状态的文字对比，以及窄窗版本状态被隐藏的问题。本机截图和浏览器检查记录在 `tmp/evidence/too-708/`。

评审回归覆盖重复打开设置、修改高级参数后返回、返回焦点、清理待确认、删除来源、晚到的任务结果，以及 680×430 CSS px 展开侧栏时的回顾布局。前后对比和交互记录位于 `tmp/evidence/too-708/review/`。
