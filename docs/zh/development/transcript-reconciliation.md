# 文件转写、原音联动与逐句校正（TOO-704）

## 目标与范围

文件页管理来源与任务，回顾页在同一会议内听原音、比较会后结果、逐句校正。复用标准文件转写 2.0、私有临时对象、原音公共时间轴和不可变稿件版本；没有第二套识别器、LLM 合并调用或录音结束后自动上传。

实现涉及共享任务 store / App 生命周期、原音提交 IPC、会话 schema 6、合并工具、审阅与采用、选版导出、配置入口和应用内单选菜单。原音与身份作用域、临时文件清理、其他供应商执行器继续沿用既有契约。

## 使用与状态

1. 「文件」记住上次服务，首次优先已配置且支持文件转写的服务。选择已有会议原音时展示标题、日期和时长；导入文件仍创建新会议。
2. 火山识别凭据与私有存储分别显示就绪状态。存储迁至「设置 → 火山文件存储」，保留 safeStorage 加密、留空保留密钥和活动任务期间禁止迁移位置规则；配置保存不提交音频。
3. 回顾原音区可「转写并校正」，确认时显示会议、时长、同步混音、临时上传和可能计费。试听音轨不改变实际提交的 mix。录音未停止、草稿未保存、已有活动任务等状态不能重复提交。
4. 两页读取同一份本地任务状态，App 每 2 秒补入结果；云端查询仍由主进程状态机负责，不新增两套网络轮询。重启只恢复本地状态，不自动上传/重投。提交未知时查询原任务 ID。
5. 已有会后稿可「生成校正版」，仅做本地计算。任务携带显式 `reconcileBaseId` 时，在会后稿持久化后自动生成；旧任务和普通文件导入不自动合并。
6. 结果保存失败、合并失败和临时副本清理失败独立显示；重试本地保存/合并不重做收费识别。已删除会议不复活，静音结果不生成空校正版。
7. 「查看稿件」不改变当前采用稿；保存审阅生成独立修订，点击「采用为当前稿」才改变导出与 AI 来源。仍有待确认项时，采用及导出提示未全部校对。原稿可随时重新采用。

## 合并规则与限制

- 输入：同一会议实时基线、会后版本、基线派生的最新人工版本。输出：独立 `reconciled`，记录基线/会后/当前来源 ID、策略版本和各区段输入/输出 ID。
- 公共时间轴排序后划分重叠候选，支持一对多及多对一。不使用数组下标或同号说话人配对，不生成全篇笛卡尔积。
- 时间边界接近（当前门槛 750ms、交并区间至少 60%）或去标点后的文字一致，且来源内部无重叠、无人工修改，才自动采用会后片段。门槛是保守对应规则，不是准确率；无标注语料的统计校准结论。
- 实时空段可补入有效会后片段；邻近人工删除或基线含无时间文字时，新增候选转待确认，避免恢复已删除段落或重复内容。
- 会后缺段保留实时文字待确认；无时间、重叠、明显错位、人工结构/来源不可追溯时保留原文候选。三方比较保护文字、姓名、归属、时间和显式删除。
- `automatic / added / manual / pending / confirmed` 区分自动采用、补入、保留人工、待确认和用户确认。用户可采用建议、保留原文或手改，并听对应原音。合并多句的手改不虚构时间。
- 原音轨道不是说话人。来源 ID 与姓名保留各自版本作用域；只有用户显式映射才跨版本复制姓名。
- 重复输入组合幂等；写入时读取最新会话，先保存会后稿再尝试合并，人工稿不因异步到达被覆盖。

## 数据、草稿与恢复

会话 schema 6 兼容旧会话，版本正规化白名单保留 `merge`。损坏来源记录不伪装成有效审阅，正文保留。已保存版本和审阅决定随会话备份/恢复；AI 材料指纹、图片时间轴沿用原实现。

人工校对草稿以本机 `delive_review_drafts` 保存，切页和重开恢复；启动在补入文件结果前读取草稿。存储满或不可读显式报告，损坏草稿不静默覆盖；会后稿可以先保存，自动合并等待草稿处理。草稿不替代正式修订，也不纳入会话完整备份；备份前应保存修订。

- 全量前端 70 文件、564 项测试通过。新增合并与并发结果补入、人工草稿持久化测试，覆盖自动替换、拆合句、漏段、重叠、无时间、人工各类修改/删除、重复回调、草稿、晚到保存、磁盘失败和缺失会议。

- CUA 操作真实组件：生成校正版、保留原文/采用会后稿、待确认采用提示、原音时间定位、键盘切换音轨及焦点返回、跨页审阅、刷新恢复未保存草稿。浅色宽窗与深色 860px 窄窗检查文件、回顾和独立存储设置，无明显遮挡。
- 云端真实链路复用当日已完成的 82 分 24 秒会议：一次提交、1,515 分句、约 2.66 万字、匿名对象 403、完成后清理确认。此后只做本地合并，不重复计费。详细历史证据见 [标准文件转写](./volc-file.md)。
- 新版实际安装到 `/Applications/DeLive SQ.app`，16 条会议和既有加密配置保留；真实长录音生成独立校正版、原音定位播放、退出重开通过，任务仍仅 1 个。该会议已有整篇旧校对稿且无逐句时间，系统保留它并列为 1 个整体待确认区段，未强行自动替换。原实时稿仍为 7,178 字，4 个版本保留。

- 自动校正不是逐字质量认证；没有逐句核听整场录音，没有新增标注集的准确率/重叠归属统计，也未重复实测全部录音硬件组合。此前实时 definite=true 缺正文问题仍保留协议错误与脱敏诊断。
