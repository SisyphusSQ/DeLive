## 设计原则

- 以浅色为主，不强制纯白；保留现有八种配色与明暗切换。使用原有主题 token、React、lucide、Select、ActionDialog、原音播放与合并工具，不引入新依赖。
- 列表保持展开，用户已删除的会议列表收起按钮不恢复；日期分组折叠是原有的另一项能力。
- 正文保持连续排版，播放器持续可达。常用操作在页签工具栏，低频操作进入展开区域；逐句审阅和版本对照才使用双列，窄窗口转为纵向。
- 查看、保存、采用各自独立。另存修订不自动采用；导出基于采用稿，已有 AI 结果展示自己的资料来源与过期提示。
- 无时间信息只限制定位原音和带时间字幕；不禁止基于已有文字、图片使用 AI。仅图片场景只描述可见草图，不捏造会议决定、人员和待办。

参考方向仍为 [Granola](https://docs.granola.ai/help-center/taking-notes/taking-notes-in-granola) 的正文留白、[Notta](https://support.notta.ai/hc/en-us/articles/37437047511195-Records-detail-page-screen-layout-and-functions-Notta-Web) 的说话人与时间关系、[Craft](https://www.craft.do/customize) 的主题与内容结构分离；没有复制其资产。

## 功能覆盖与预览入口

| 正式能力或需求 | 本次设计位置及交互 |
| --- | --- |
| 会议搜索、日期分组、标题、标签、专题、删除 | 左侧列表；右上“会议信息”编辑并保存/取消，删除需确认；保存失败保留输入 |
| 摘要、标题/标签建议、章节、行动项 | 摘要正文及“会议信息建议”；应用标题、合并标签、查看章节和引用；待办勾选仅用于本次预览 |
| AI 文本校对 | 摘要内“AI 校对”；快速校正/逐项检测、类别筛选、修改原因、单项/全部接受或拒绝、原文对照、另存修订、重置 |
| 对话 | 新建/切换/删除历史会话，问题和回答复制、重新生成、预设追问、Enter 发送、Shift+Enter 换行、输入法组合保护、文字与图片引用 |
| 思维导图 | 保留笔记导图和大纲；补充 Markdown 编辑/保存/放弃、复制、缩放拖动、全屏/Esc 返回、SVG/PNG 合成导图导出；编辑草稿跨页签保留 |
| 转录与说话人 | 查看版本、对照版本、筛选包括未知说话人；编辑段落正文/时间/归属/姓名、删除段落、添加说话人、明确手动对应关系 |
| 逐句合并 | 原稿与会后建议、原因、只看待确认/全部、前后切换、回听、保留原文/接受建议/人工修订；保存失败保留输入，采用单独确认 |
| 编辑草稿 | 转录草稿与未保存提示保留在本次预览中，跨页签或会议返回可继续；草稿未保存时不能采用；放弃需确认 |
| 旧无时间稿恢复（TOO-707） | 历史稿 Story 提供恢复入口及确认；从已有结构化会后稿创建新修订、保留旧全文、展示待确认区段；另行采用才改变导出来源 |
| 图片资料 | 右上入口；插入、拖入/粘贴替身、原图预览、编辑时间与说明、定位、删除确认；图片变化让旧 AI 结果显示过期 |
| 导出 | 右上入口选择 TXT/MD/SRT/VTT，展示采用稿与待确认提醒，无有效时间时禁用 SRT/VTT；会议导出仅预览确认，不写出文件 |
| 会后任务 | 转录页“会后转写与校正”；已有稿本地校正、重新识别前上传/计费确认、查询原任务、停止清理、待保存重试、清理未确认重试、详情 |
| 异常与资料来源 | AI 未配置、处理中、失败、资料过期；校正来源缺失不应用；原音缺段可跳下一位置 |

## 隔离与限制

- 所有会议、姓名、文字、摘要、回答和图片均为合成资料。静音 WAV 仅用于播放器交互；不读取真实会议或个人文件。
- 预览拒绝在真实 Electron 环境启动；文件任务变更 API 使用阻断替身，移除 Vite 业务代理，CSP 限制连接为同源与本地热更新。
- 启动/重置只覆盖当前 Storybook 来源内的合成会话存储。提案编辑、版本、图片和对话保存在组件状态，刷新或重置会还原，不代表正式磁盘持久化。
- AI 回答、检测结果和任务状态为可控示例。自由提问明确提示不能在本地回答；生成/重试入口只切换预览状态，完成状态由顶部选择器查看，不调用模型或 ASR。
- 图片插入/拖入/粘贴统一使用合成 SVG 草图，不读取、上传所选文件。AI 校对使用两处固定示例建议展示操作，不代表真实模型质量。
- 会议 TXT/MD/SRT/VTT 导出只预览来源与限制；导图 SVG/PNG 复用现有导出工具，可由点击下载本地合成内容。
- 预览不修改正式页面、不部署。刷新持久化、真实音频/AI/云任务、老数据迁移和收费流程没有进行业务验收。用户随后授权提交推送与回写 Linear；这不构成开始正式页面实现或发版的授权。
