# 设置

从录制、文件或会议进入设置时，可以返回原页面继续。文件页保留所选音频和来源，回顾页保留所查看的会议和稿件。火山转写凭据、文件私有存储和 AI 配置各自保存。配置保存后，录制或上传仍由用户发起。


DeLive SQ 设置按服务商、火山文件存储、AI 后处理、外观、开放 API、云端备份、数据管理和关于八个分组分组。

## 服务商

### Provider 选择

可选火山云端语音转写、本地 OpenAI 兼容、FunASR／SenseVoice 或 whisper.cpp。按服务配置凭据、端点、模型和语言提示。

### 配置测试

提供「测试配置」的服务可在录制前检查凭据和连通性。

![设置 — 服务标签页](/images/screenshot-settings-api.png)

### 本地服务发现

对于 **本地 OpenAI 兼容** 和 **FunASR / SenseVoice**，DeLive 可以：
- 在配置的 Base URL 处探测服务
- 通过 `/v1/models` 列出已安装的模型
- 检测到 Ollama 时可拉取模型（仅本地 OpenAI 兼容）

### Runtime 设置

对于 **本地 whisper.cpp**，内置的 Runtime 指南帮助你：
- 导入或下载 `whisper-server` 二进制文件
- 导入或下载 `.bin` / `.gguf` 模型
- 测试 Runtime 配置

## 应用偏好

### 界面语言

在 **中文**（默认）、**英文**和 **韩文** 之间切换。

### 颜色主题

八种配色方案：**紫罗兰**（默认）、**青蓝**、**玫瑰**、**翡翠**、**琥珀**、**樱粉**、**石板灰**、**橙韵**。每种都支持完整的明暗模式。明暗切换在主侧栏底部。

### AI 后处理

配置用于 AI 功能的 OpenAI 兼容端点：

| 字段 | 说明 | 默认值 |
|------|------|--------|
| Base URL | Chat completions 端点 | `http://127.0.0.1:11434/v1` |
| 模型 | 模型标识符 | — |
| API Key | 可选认证 | — |
| 提示语言 | `zh`、`en` 或 `ko` | `zh` |

### Open API

控制对 DeLive 数据的外部访问（仅 Electron）：

| 设置 | 说明 |
|------|------|
| **启用 Open API** | 开关本地 REST API 和 WebSocket |
| **访问令牌** | 必填的 Bearer Token，开启 API 时自动生成 |
| **生成随机令牌** | 确认后创建新的随机令牌，旧令牌随即失效 |
| **端点 URL** | 显示 REST 和 WebSocket URL，带复制按钮 |

::: warning
清空令牌后，API 会拒绝所有请求，直到设置新的令牌。
:::

### 数据管理

- **导出** — 将会话、标签、主题和设置下载为 JSON，不包含图片和原音实体
- **导入** — 从备份文件恢复（覆盖或合并）

### 桌面集成

- **开机自启** — 系统登录时启动 DeLive（Windows 和 macOS）
- **更新** — SQ 发行包采用手动下载安装，应用内自动更新关闭
- **诊断导出** — 生成脱敏的 JSON 包用于故障排查

## 火山文件存储

标准文件转写除识别凭据外，还需要私有 S3 兼容存储。实时识别不需要此配置。

在「设置 → 火山文件存储」填写 HTTPS endpoint、区域、私有桶、专用前缀和访问凭据。以北京 TOS 为例：endpoint `https://tos-s3-cn-beijing.volces.com`，区域 `cn-beijing`，关闭「使用路径式桶地址」。桶必须从未启用版本控制，禁止公开访问，并具有必要的上传、读取、删除与分片清理权限。详见 [存储契约](../development/volc-file.md)。

凭据由系统安全存储加密；留空保留已保存值。有活动任务或尚未清理副本时不能更换存储位置。从会议进入配置会保留来源，保存后可返回继续；保存配置本身不提交音频。

## 工作台导航与保存

窄窗口中设置分组自动换行，表单独立滚动。服务商、文件存储、AI 的未保存修改会在切换分组、主导航或使用命令面板时提示；取消继续编辑，确认放弃后才离开。外观、开放 API 和云端备份延续各自即时保存的现有行为。

顶部命令面板支持五个主页面，导出命令打开“数据管理”供用户选择导出操作。关于页始终展示版本；仅支持自动更新的发行版显示更新按钮，其状态来自桌面更新事件。
